# Matriz editorial privada del curso (89 elementos)

Este archivo no se presenta en la interfaz de GramLab. Sirve para controlar cobertura sin convertir la aplicación en un curso por clases ni publicar enlaces o transcripciones.

## Criterio de evidencia

- Se descargaron subtítulos permitidos para 85 de los 89 elementos de la lista.
- Los elementos 24, 41, 44 y 47 no ofrecieron subtítulos y quedan **pendientes de notas del usuario**; no se marcan como cubiertos.
- Los apuntes visuales aportados por el usuario verifican los bloques de tiempos, pronombres/posesivos, artículos, cantidad, preguntas, preposiciones, modales, `there be`, `have got`, `used to`, `ever/never`, presente perfecto, participios, `to/for` y ubicación.
- Cuando el título no declara un tema concreto, la fila se conserva como **pendiente de indexación fina** aunque exista subtítulo. Así se evita inventar una regla o afirmar una cobertura no revisada.
- “Cubierto” significa que existe una ficha original de GramLab que responde al concepto; no que se haya copiado el contenido del video.
